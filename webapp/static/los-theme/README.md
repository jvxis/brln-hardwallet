Theme CSS and Space Grotesk fonts are bundled locally from jvxis/brln-os-light 0.5.48-Beta (49cb0b68) UI production build. Generated by tools/sync_los_theme.cjs <LOS-ui-directory> after npm run build. This keeps root theme/palette variables, body, section-card, button and input-field rules, including dark-only themes. No remote styles/fonts are loaded. MIT and SIL Open Font licenses are included. Appearance enums arrive from the authenticated LOS launcher in the URL fragment, are validated, removed from the address bar and remembered locally. Reopen from the Store after changing LOS appearance. No login token or account data is transferred.
