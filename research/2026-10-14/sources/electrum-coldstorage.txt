<span id="coldstorage"></span><h1>Cold Storage<a class="headerlink" href="#cold-storage" title="Link to this heading"></a></h1>
<p>This document shows how to create an offline wallet that
holds your Bitcoins and a watching-only online wallet that
is used to view its history and to create transactions that
have to be signed with the offline wallet before being
broadcast on the online one.</p>
<section id="create-an-offline-wallet">
<h2>Create an offline wallet<a class="headerlink" href="#create-an-offline-wallet" title="Link to this heading"></a></h2>
<p>Create a wallet on an offline machine, as per the usual process (file
-&gt; new) etc.</p>
<p>After creating the wallet, go to Wallet -&gt; Information.</p>
<img alt="_images/wallet_info.png" src="_images/wallet_info.png" />
<p>The Master Public Key of your wallet is the string shown in this popup
window.  Transfer that key to your online machine somehow.</p>
</section>
<section id="create-a-watching-only-version-of-your-wallet">
<h2>Create a watching-only version of your wallet<a class="headerlink" href="#create-a-watching-only-version-of-your-wallet" title="Link to this heading"></a></h2>
<p>On your online machine, open up Electrum and select File -&gt;
New/Restore. Enter a name for the wallet and select “Standard wallet”.</p>
<img alt="_images/standard_wallet.png" src="_images/standard_wallet.png" />
<p>Select “Use public or private keys”</p>
<img alt="_images/public_or_private.png" src="_images/public_or_private.png" />
<p>Paste your master public key in the box.</p>
<img alt="_images/restore_key.png" src="_images/restore_key.png" />
<p>Click Next to complete the creation of your wallet.
When you’re done, you should see a popup informing you that you are opening a watching-only wallet.</p>
<img alt="_images/watchingonly.png" src="_images/watchingonly.png" />
<p>Then you should see the transaction history of your cold wallet.</p>
</section>
<section id="create-an-unsigned-transaction">
<h2>Create an unsigned transaction<a class="headerlink" href="#create-an-unsigned-transaction" title="Link to this heading"></a></h2>
<p>Go to the “send” tab on your online watching-only wallet,
input the transaction data and press “Preview”. A window pops up:</p>
<img alt="_images/unsigned.png" src="_images/unsigned.png" />
<p>Press “save” and save the transaction file somewhere on your computer. Close the
window and transfer the transaction file to your offline
machine (e.g. with a usb stick).</p>
</section>
<section id="get-your-transaction-signed">
<h2>Get your transaction signed<a class="headerlink" href="#get-your-transaction-signed" title="Link to this heading"></a></h2>
<p>On your offline wallet, select Tools -&gt; Load transaction -&gt; From file
in the menu and select the transaction file created in the previous
step.</p>
<img alt="_images/sign.png" src="_images/sign.png" />
<p>Press “sign”. Once the transaction is signed, the Transaction ID
appears in its designated field.</p>
<img alt="_images/signed.png" src="_images/signed.png" />
<p>Press save, store the file somewhere on your
computer, and transfer it back to your online machine.</p>
</section>
<section id="broadcast-your-transaction">
<h2>Broadcast your transaction<a class="headerlink" href="#broadcast-your-transaction" title="Link to this heading"></a></h2>
<p>On your online machine, select Tools -&gt; Load transaction -&gt; From File
from the menu. Select the signed transaction file. In the window that
opens up, press “broadcast”. The transaction will be broadcasted over
the Bitcoin network.</p>
</section>
</section>
